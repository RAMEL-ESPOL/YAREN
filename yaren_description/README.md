### Package Description

This package contains the necessary files for simulating the virtual model of the robot in **Gazebo**. In addition, it integrates the **hospital_world** subpackage to simulate a virtual hospital environment, enabling validation of the robot's behavior in a controlled clinical scenario.

### Main Features

- Simulation of the robot's 3D model in Gazebo.  
- Integration of a virtual hospital environment using the **hospital_world** subpackage.
